# DA Interview Prep

A focused mock-interview preparation system for aspiring Data Analysts targeting GCC, product-based, marketing, and e-commerce roles.

It helps candidates practice the technical concepts and business thinking commonly assessed in Data Analyst interviews.

🔗 **Live Demo:** [Open DA Interview Prep](https://vedp9.github.io/da-interview-prep/)  
💻 **Repository:** [github.com/vedp9/da-interview-prep](https://github.com/vedp9/da-interview-prep)

## Overview

DA Interview Prep is a web-based study resource built to support structured preparation for Data Analyst interviews.

The content focuses on key areas such as SQL, Python, statistics, A/B testing, marketing analytics, e-commerce metrics, and business case thinking.

## Topics Covered

- SQL queries, joins, aggregations, window functions, and data analysis
- Python fundamentals for data analysis
- Statistics and probability concepts
- A/B testing and experiment analysis
- Marketing funnel and campaign metrics
- E-commerce metrics and product analytics
- Data cleaning, dashboards, and business insights
- Behavioral and scenario-based interview preparation

## Who It Is For

- Aspiring Data Analysts
- Candidates preparing for GCC and product-company roles
- Analysts preparing for marketing, e-commerce, or business analytics interviews
- Learners who want a structured revision resource before interviews

## Features

- Curated Data Analyst interview-preparation content
- Topic-based guidance across technical and business areas
- Simple, responsive web interface
- Publicly accessible through GitHub Pages
- No installation or account required

## Tech Stack

- **Frontend:** HTML, CSS, and JavaScript
- **Hosting:** GitHub Pages
- **Deployment:** GitHub Actions

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/vedp9/da-interview-prep.git
```

2. Navigate into the project folder:

```bash
cd da-interview-prep
```

3. Open `index.html` in a browser.

You can also use the VS Code **Live Server** extension for local development.
